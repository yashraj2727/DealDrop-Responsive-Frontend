# DealDrop 🛍️
A Responsive Product Deal Page — DecodeLabs Internship Project 1

## 📌 About
DealDrop is a static responsive frontend project built as part of my 
Full Stack Development Internship at DecodeLabs (Batch 2026).

It showcases the lowest manually researched prices on Nike, Adidas, 
boAt, Sony, Samsung & Apple products from Amazon & Flipkart (as of May 2026).

> ⚠️ Note: Prices are manually collected and not auto-updated.
> This is a frontend UI project, not a live price tracking service.

## 🤖 Built With AI Assistance
This project was built with the help of Claude AI (by Anthropic) 
for code generation and structure. All product research, price 
verification, image collection, and design decisions were guided by me.

## 🛠️ Tech Stack
- HTML5 — Semantic landmarks
- CSS3 — Grid, Flexbox, Mobile-First
- Vanilla JavaScript — Animations, interactions
- No frameworks used

## ✅ Features
- Fully responsive (mobile, tablet, desktop)
- Real product images
- Manually verified prices (May 2026)
- Direct Amazon & Flipkart links
- Scroll reveal animations
- Sticky navbar + hamburger menu
